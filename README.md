# 📄 Resume Matcher

**Resume Matcher** is a smart application that helps generate a personalized resume tailored to a specific job description. By combining user input and AI-driven filtering, the app ensures your resume highlights only the most relevant details for each job.

---

## 📌 Overview

This app allows users to input their personal details—including:

- Name
- Contact Information
- Education
- Skills
- Experience
- Projects

These details are stored in a **vector database**. When a job description is provided, the system intelligently matches and extracts the most relevant information from the user's data to generate a **custom resume**.

Built using:

- 🐍 Python  
- 📊 Streamlit  
- 🔗 LangChain  
- 🧠 ChromaDB  
- 💡 Cohere Embeddings  

This tool helps job seekers effortlessly create **targeted, professional resumes**.

---

## 🚀 Features

- 🧠 **AI-Powered Resume Matching**  
  Tailors your resume to the job description using semantic similarity.

- 📚 **Vector Database Integration**  
  Stores user data in ChromaDB for efficient retrieval.

- ✍️ **Minimal Input Required**  
  Fill out your details once—reuse and regenerate for any job.

- ⚙️ **Streamlit Interface**  
  Simple and intuitive UI for a smooth experience.

- 🔗 **Cohere Embeddings**  
  Ensures semantic accuracy in matching resume content to job descriptions.
